# Demo scenario: NovaPay credential path

1. Start the stack with `docker compose up --build`.
2. Open the dashboard at `http://localhost:5173` and the safe NovaPay lab at `http://localhost:8081`.
3. In the lab, open the operations workspace, `.env.production`, cloud migration console, storage buckets, `customer_export.csv`, and its download button—in that order.
4. Watch the dashboard reconstruct the sequence from Discovery through Credential Access and Cloud Discovery to Collection, then recommend sandbox containment.

All values are harmless fake values and all actions occur within the local demo environment.
